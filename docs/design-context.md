# Design context
## Primary persona — Sofía Herrera
22, Medellín. Communication student and BookTok creator (8k). Reads ~60 books/year (romantasy, thriller, contemporary) on Kindle and secondhand paperbacks, on Android. On Goodreads since 2019 for the Reading Challenge; double-logs in StoryGraph for stats; builds monthly wrap-ups in Canva because Goodreads screenshots look dated.
## Hypotheses (Lean UX Canvas)
- H1: We'll increase books logged per month if heavy readers can change a book's status in one tap from any cover.
- H2: We'll improve store ratings if readers can find books from partial or misspelled titles with typo-tolerant search.
- H3: We'll increase 30-day retention if new users discover relevant reads on a home built from their onboarding tastes.
- H4: We'll reduce migration to competitors if Gen Z readers can express their reader identity with a visual profile (top 4, yearly recap, shareable cards).
- H5: We'll reduce fraudulent reviews if only published books marked as read can be reviewed, with a verified-read badge.
## Structural principles
Log from any cover · One search · Personal home · Community is a main tab · Profile as identity · Verified reviews · Cover first.
